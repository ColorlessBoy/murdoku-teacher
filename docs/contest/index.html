原题规则：基础 Murdoku 规则 · 这次没有凶手——找出宝藏坐标（ROW / COLUMN）即破案。 更多规则与图例见右侧「怎么玩」。
怎么玩 · 规则与图例
目标：和普通 Murdoku 一样，每行每列各放一个人；但这次不找凶手，而是找出宝藏的坐标（ROW / COLUMN）。
原题提示：宝藏就在最后一格（The Treasure is in the very last square）；有两个格子就在门前。
船：Sloop、Frigate、Galleon 都算 ship，并且各自算独立区域。
可占用：ships（Sloop / Frigate / Galleon）、bed、chair、hammock
不可占用：fire · tree · flowers · shark · sack · pig · tombstone · crate · rope · barrel · shelf · shrub · table · boulder
