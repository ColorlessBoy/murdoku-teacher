墨墨 · Murdoku 陪练

扩展内独立 agent。API Key 只存在本机 chrome.storage.local，日志自动脱敏。

模型设置

支持任意 OpenAI 兼容网关；测试会发一条最小请求并写入日志。

日志

日志包含 LLM 请求/响应、盘面改动、用户消息、错误；Key 与 Authorization 自动替换为 «redacted»。

审计账本（框架记录）


      
每个格子的 before → after、批次号、来源（user-place / auto-x / user-note / user-x / user-clear）都在这里；未解决项会强制带进每次 prompt。

    


    

      
使用

      

        1. 打开 Murdoku 盘面，左侧会自动出现墨墨。

        2. 在侧栏选 教学 / 考试；考试模式下你动盘面，墨墨会自动提问；回答写在底部输入框。

        3. 输入 /clear 清空盘面（保留聊天与日志）。

        4. 侧栏 ⚙ 回到本页；日志会持续记录，用于复盘与修复。
