# 墨墨 · Murdoku 陪练（Chrome 扩展）

在 Murdoku 页面右侧注入墨墨侧栏，支持**教学模式**与**考试模式**。

## 安装

1. `chrome://extensions` → 打开开发者模式 → 加载已解压的扩展程序 → 选本目录；
2. 打开 Murdoku 关卡页，右侧出现侧栏；
3. 点 ⚙ 配置 API Key / Base URL / 模型（任意 OpenAI 兼容端点）。

## 模式

- **教学**：老师解题、学生质疑。老师会直接写盘（笔记/落子/X），每步讲清前提→规则→结论；做完一步停下等学生明确“接受/继续”，不接受就继续解释同一步。
- **考试**：学生解题、老师审逻辑。老师只提问/判定，不替学生落子，不泄露答案。

## 命令

- `/clear`：只清盘面（放置/笔记/X）；
- `/new`：清空聊天、账本、旧上下文，盘面保留；教学模式下老师会自动开场；
- `/new logs`：同上并清空日志；
- `/reload`：开发用，重载扩展并刷新页面。

## 内置教案（备课）

- `lessons/puzzle-minigolf-hard.json`：官方解 + 推导链 + 易错点；
- `src/lessons.js`：静态打包（同步加载，不发起网络请求），未知关卡不自动备课；
- 老师用教案核对，但不把最终凶手/整盘答案直接说给学生。

## 开发

- 改完代码：在侧栏输入 `/reload`，扩展自动重载并刷新页面（不需要手动点扩展刷新）；
- 单元测试：`node --test test/*.test.mjs`；
- 诊断：侧栏「盘面检测」头部显示备课状态；`#mm-debug` 含 prep/queue/日志。

## 隐私

API Key 只存 `chrome.storage.local`；日志里 redaction；不向除所配置模型端点外的服务器发送盘面/对话。
